How to add extensions to Brain2 Web API:
1. stop Bizerba BRAIN2 WebServer service in services
2. copy all .dll from Extensions folder to C:\Program Files\Bizerba\BRAIN2\WebServer folder
3. start Bizerba BRAIN2 WebServer service

To start app:
unzip OrderAppHost.zip file to c:\Bizerba\OrderAppHost folder
start start-server.bat
doubleclick on http://localhost:5000
