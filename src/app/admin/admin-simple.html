💡 Setup Instructions

  1. Create custom jobs in Brain2 Scheduler with descriptive names (e.g., "SendToLine1", "ProcessBatch")
  2. Click "Add Action Button" to create a new button configuration
  3. Enter a button label that will appear on the Actions page for operators
  4. Optionally enter a production line name for organizational purposes
  5. Enter the job name that exactly matches your Brain2 custom job
  6. Use ▲ ▼ arrows to reorder buttons on the Actions page

Note: Users with SchedulerConfiguration right will see these buttons on the Actions page and can trigger the configured jobs.
